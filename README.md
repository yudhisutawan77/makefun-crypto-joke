## Entry

> I opened 100x leverage so my liquidation price and my entry price could finally meet. They did. In four minutes.

(112 characters — under the 200-character cap.)

## How it works

`main.py` writes the joke to `$ENTRY_OUT` (a `.txt` file path, or a directory
in which `entry.txt` is written), or `$ENTRY_OUT_DIR/entry.txt`, defaulting to
`/output/entry.txt`, and prints it to stdout. Standard library only, no network.
